# MoonShine — примеры ресурсов и полей

Примеры из проекта на Laravel + MoonShine.

## Что внутри

- `SlugField` — кастомное поле с автогенерацией slug из заголовка.
- `NurseryResource` — пример ресурса с BelongsTo и HasMany.

## Ключевые моменты

- Кастомное поле расширяет стандартное.
- Ресурс связывает модель с админкой.
- Связи BelongsTo и HasMany — с поиском и обязательностью.
- Валидация через `rules()`.
