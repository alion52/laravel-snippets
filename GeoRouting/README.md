# GeoRouting — ЧПУ для геокаталога

Пример из проекта каталога питомников на Laravel.

## Задача

Поддержать ЧПУ-страницы:

- `/{region}/` — питомники в области
- `/{region}/{plant}/` — растения в области
- `/{city}/` — питомники в городе

Каждая страница — с хлебными крошками, SEO-метатегами, H1 и текстом.

## Решение

- `GeoRouteService` — разбор URL и генерация ссылок.
- `GeoController` — рендеринг страниц, хлебные крошки, SEO.
- `routes.php` — регистрация маршрутов с ограничениями по slug.

## Ключевые моменты

- Разбор URL через `match` и `instanceof`.
- Единая точка генерации URL для сущностей.
- Базовый запрос с фильтром по региону, городу, растению.
- Хлебные крошки строятся динамически.
- SEO-тексты зависят от контекста.
