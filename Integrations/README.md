# Integrations — эквайринг Альфа-Банка

Пример из проекта на Yii2 / Laravel.

## Что внутри

- `AlfabankClient` — клиент для работы с API банка: регистрация, статус, возврат.
- `PaymentWebhookHandler` — обработка вебхуков: проверка подписи, обработка статусов, защита от повторной обработки.

## Ключевые моменты

- Полный цикл: инициализация, оплата, вебхуки, возвраты.
- Проверка подписи через HMAC.
- Защита от повторной обработки.
- Логирование операций.
- Матчинг статусов через `match`.
