# Laravel Snippets

Обезличенные примеры кода из моих коммерческих проектов. Показывают подходы и архитектурные решения. Код заказчиков не раскрывается.

## Что внутри

- **GeoRouting** — ЧПУ для геокаталога: области, города, категории.
- **QueryFilters** — pipeline фильтров для каталога.
- **MoonShine** — кастомные поля и ресурсы для админки.
- **Integrations** — эквайринг Альфа-Банка, вебхуки.
- **Sync** — синхронизация между сайтами.
