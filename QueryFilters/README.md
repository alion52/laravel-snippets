# QueryFilters — pipeline фильтров

Пример из проекта каталога на Laravel.

## Задача

Поддержать фильтры каталога: цена, категория, наличие, бренд. Фильтры должны легко добавляться и комбинироваться.

## Решение

- Базовый класс `ProductFilter`.
- Каждый фильтр — отдельный класс: `PriceFilter`, `CategoryFilter`, `StockFilter`, `BrandFilter`.
- `FilterPipeline` применяет фильтры по цепочке.
- Легко добавлять новые фильтры.

## Ключевые моменты

- Единый интерфейс `apply(Builder $query): Builder`.
- Параметры передаются в конструктор.
- Pipeline применяется в контроллере одной строкой.
- Легко тестировать каждый фильтр отдельно.
