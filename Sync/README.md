# Sync — синхронизация между сайтами

Пример из плагина WP Cross-Site Sync.

## Что внутри

- `CollectorExample` — сбор данных с источника: посты, мета, ACF, термины.

## Ключевые моменты

- Сбор постов через `WP_Query`.
- Сбор метаданных, ACF-полей, терминов.
- Поддержка исключений через `post__not_in`.
- Передача данных в `Sender` для отправки через REST API.
